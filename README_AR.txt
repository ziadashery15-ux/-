طريقة الرفع الجديدة:
1) ارفع ملف index.html فقط إلى GitHub واستبدل النسخة القديمة.
2) افتح رابط الموقع وانتظر دقيقة أو دقيقتين.
3) احذف الاختصار القديم من الشاشة الرئيسية.
4) افتح الموقع من Chrome ثم اختر Add to Home screen / Install app.
ملاحظة: هذه النسخة مدمج بداخلها صور المنصة، لذلك لا تحتاج مجلد images لكي تظهر الصور داخل الصفحة.
