# Ziad Study Hub V6
## النسخة اللي فيها لوحة تحكم فعلية

ارفع **كل محتويات المجلد** إلى نفس GitHub repository:
- index.html
- manifest.webmanifest
- sw.js
- مجلد images كاملًا

### التحكم من داخل المنصة
من زر **⚙️ الإدارة** تقدر تضيف:
- فيديو برابط YouTube أو رابط فيديو مباشر
- PDF / مذكرة
- اختبار بسؤال وإجابة
- سؤال
- درس نصي

المحتوى يُحفظ في المتصفح على نفس الجهاز باستخدام LocalStorage. ملفات الـPDF تُحفظ داخل المتصفح، لذلك يُفضّل ألا يتجاوز الملف 12MB.

### مهم جدًا
GitHub Pages وحده لا يوفّر قاعدة بيانات أو تخزينًا سحابيًا للمحتوى. لذلك هذه النسخة تعمل فعليًا داخل المتصفح، لكن المحتوى الذي تضيفه من جهازك **لن يظهر تلقائيًا على جهاز آخر**.

لو أردت لاحقًا أن يكون المحتوى مركزيًا ويظهر لكل الأجهزة، نربط لوحة الإدارة بقاعدة بيانات وتخزين سحابي.


### التسكات
من داخل المنصة يوجد قسم **التسكات** لإضافة التاسكات مع المادة والتاريخ والوقت والملاحظات، وتعليم التاسك كمكتمل أو حذفه. التقدم يُحفظ على نفس الجهاز والمتصفح.


### الجدول الأسبوعي
قسم **التسكات** الآن يعرض جدول زياد الأسبوعي الأصلي من السبت إلى الجمعة، مع كل المواعيد والدروس والجيم وكرة القدم، ويمكن وضع علامة ✓ على كل مهمة عند إنجازها. التقدم محفوظ على نفس الجهاز.
